# ESP32 DLNA MediaRenderer — 网易云音乐投屏播放器

> 基于 ESP-GMF 的 DLNA 音频渲染器，支持网易云/QQ音乐/酷狗等 App 投屏播放，PCM5102A DAC 高品质输出，128x160 彩屏显示唱片动画与歌词。

## 适用人群

- **音乐爱好者** — 想用手机投屏到桌面音箱/功放，享受高品质音频
- **DIY 玩家** — 手上有 ESP32-S3 + PCM5102A 开发板，想折腾 DLNA 音频流
- **不想买成品** — 不想花几百块买蓝牙音箱，用 ESP32 自制 WiFi 音频接收器

## 功能

### 音频
- ✅ **DLNA 投屏播放** — 网易云/QQ音乐/酷狗等支持 DLNA 的 App 均可投屏
- ✅ **高品质音频** — PCM5102A DAC（112dB 动态范围），MCLK 直供低 jitter
- ✅ **HTTP 流解码** — MP3/AAC/WAV/FLAC/OGG，1MB PSRAM 缓冲防卡顿
- ✅ **采样率/位深自适应** — 解码器事件驱动，I2S 原子重配置，支持 16/24-bit
- ✅ **ALC 软音量** — 平方曲线映射 0-100 → -64~0 dB，旋钮/手机端同步
- ✅ **GENA 事件同步** — 手机端实时显示播放状态，歌曲自动切换

### 显示（ST7735S 128x160 彩屏）
- ✅ **唱片旋转动画** — 封面圆形裁剪 + 匀速旋转，唱针 ease-out 落针
- ✅ **动态背景** — 从封面提取主色，Bayer 4×4 有序抖动渐变（消除 RGB565 色阶）
- ✅ **歌词同步** — 3 行歌词显示 + 逐字高亮 karaoke + 超长行自动左移
- ✅ **旋钮交互** — 旋转切换焦点，按压播放/暂停，焦点边框渐显动画
- ✅ **进度条** — 平滑过渡，实时更新当前/总时长

### 控制
- ✅ **旋钮控制** — 旋转调节音量，按压暂停/播放，长按切换歌词界面
- ✅ **手机端控制** — 播放/暂停/上下曲/音量/Seek，手机与旋钮双向同步

## 工作原理

```
┌──────────────────────────────────────────────────────────────┐
│                         手机 (网易云)                         │
│  ┌────────────┐    ┌──────────────────┐    ┌──────────────┐  │
│  │ 选择投屏    │───▶│  DLNA 控制协议    │───▶│  HTTP 代理    │  │
│  │ "MS01B"    │    │  SetAVTransport  │    │  (音频流 URL)  │  │
│  └────────────┘    └────────┬─────────┘    └──────┬───────┘  │
│                             │                     │          │
└─────────────────────────────┼─────────────────────┼──────────┘
                              │ SOAP                │ HTTP 流
                              ▼                     ▼
┌──────────────────────────────────────────────────────────────┐
│                     ESP32-S3 (GMF 渲染器)                     │
│                                                              │
│  ┌────────────────────────────────────────────────────────┐  │
│  │  GMF Pipeline: io_http → aud_dec → aud_alc → io_i2s   │  │

│                                                              │
│  ┌──────────┐  ┌──────────┐  ┌──────────┐  ┌──────────────┐ │
│  │ SSDP     │  │ SOAP     │  │ 旋钮     │  │ ST7735S 屏幕 │ │
│  │ 设备发现  │  │ 控制接口  │  │ 音量/暂停 │  │ 唱片+歌词    │ │
│  └──────────┘  └──────────┘  └──────────┘  └──────────────┘ │
└──────────────────────────────────────────────────────────────┘

┌──────────────────────────────────────────────────────────────┐
│                    PCM5102A DAC 模块                          │
│                    → 功放 / 耳机 / 音箱                       │
└──────────────────────────────────────────────────────────────┘
```

## 支持的开发板

| 芯片 | 常见开发板 | 架构 | Flash | PSRAM | 状态 |
|------|-----------|------|-------|-------|------|
| **ESP32-S3** | ESP32-S3-DevKitC-1, ESP32-S3-WROOM-1 (N16R8) | Xtensa 双核 | 16MB | 8MB (Octal) | ✅ 已验证 |
| **ESP32** | ESP32-DevKitC, NodeMCU-32S | Xtensa 双核 | 4MB+ | 可选 | ⚠️ 内存紧张 |

> ⚠️ **Flash/PSRAM 要求**
> - 推荐 **16MB Flash + 8MB PSRAM**（ESP32-S3-WROOM-1 N16R8）
> - 最低 **4MB Flash + 2MB PSRAM**（需要减小缓冲区）
> - 无 PSRAM 的芯片不支持（1MB HTTP 缓冲 + LVGL 帧缓冲需要 PSRAM）

## 快速开始

### 方式一：下载固件直接烧录（推荐）

从 [Releases](https://github.com/MYHealer/dlna-esp32/releases) 下载最新固件包。

```bash
# 安装 esptool
pip install esptool

# 烧录（ESP32-S3，COM 号按实际修改）
esptool --chip esp32s3 -p COM31 -b 460800 \
  --before default_reset --after hard_reset \
  write_flash --flash_mode dio --flash_size 16MB --flash_freq 80m \
  0x0 bootloader.bin \
  0x8000 partition-table.bin \
  0x10000 dlna.bin
```

### 方式二：从源码构建

需要 ESP-IDF v5.5+ 环境。

```powershell
# 编译
.\build.ps1

# 烧录
.\flash.ps1
```

## 使用步骤

**① 烧录固件** → **② 连接硬件**（PCM5102A + 屏幕 + 旋钮）→ **③ 上电连 WiFi**

**④ 投屏播放**

1. 手机连接同一 WiFi
2. 手机打开网易云音乐，播放一首歌
3. 点击播放界面右上角的 **投屏按钮**
4. 选择设备 **"MS01B"**
5. 音乐从 PCM5102A 输出，屏幕显示唱片旋转 + 歌词

**⑤ 控制**

| 操作 | 效果 |
|------|------|
| 旋钮旋转 | 调节音量 |
| 旋钮按压 | 暂停/播放 |
| 旋钮长按 | 切换歌词/主界面 |
| 旋钮左右旋转（焦点模式） | 切换 上一曲/播放/下一曲 |

## 技术架构

### GMF 音频管线

本项目使用 **ESP-GMF**（Espressif 通用媒体框架），弃用旧版 ESP-ADF。

```
esp_gmf_pool → esp_gmf_pipeline
  ├── io_http      (HTTP 流拉取，PSRAM 缓冲)
  ├── aud_dec      (解码器：MP3/AAC/FLAC/WAV/OGG)
  ├── aud_alc      (ALC 软音量控制，0-100 → -64~0 dB)
  └── io_codec_dev (I2S 输出，直接 i2s_channel_write)
```

关键设计：
- **Job 消耗型**：每次 `_do_play()` 必须 `reset() + loading_jobs() + run()`，stop 后 working 链表被清空
- **事件驱动**：解码器解析流头后上报 `ESP_GMF_INFO_SOUND` 事件，I2S 原子重配置（disable → reconfig_clock → reconfig_slot → enable）
- **绕过 esp_codec_dev 软件音量**：其默认 volume=0（-96dB 静音），直接 `i2s_channel_write()` 输出

### LVGL 显示

```
ST7735S 128x160 (RGB565, SPI)
├── 主界面
```

### 双核分工

| Core | 任务 | 优先级 |
|------|------|--------|
| Core0 | WiFi + HTTP + DLNA 协议 + LVGL UI | 内核 + 5-6 |
| Core1 | GMF 音频管线（解码 + ALC + I2S） | 8-9（最高） |
